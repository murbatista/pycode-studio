# 🐍 PyCode Studio — Ambiente Online de Programação Python

**Um ambiente de desenvolvimento Python acessível diretamente pelo navegador, desenvolvido para facilitar o aprendizado, a prática e o ensino de programação.**

< **Acesse a plataforma:** [PyCode Studio](https://pycode-studio.onrender.com/)

---

## 🚀 Sobre o projeto

O PyCode Studio é uma plataforma online de programação Python que reúne ferramentas para escrever, executar, testar e aprender Python em um único ambiente.

O projeto foi desenvolvido com foco na experiência de estudantes e professores, permitindo praticar programação sem precisar instalar um ambiente de desenvolvimento no computador.

## ✨ Funcionalidades

- **Editor de código:** ambiente de edição com destaque de sintaxe.
- **Execução Python:** escreva e execute programas diretamente na plataforma.
- **Tutor IA:** assistente integrado ao Gemini para auxiliar no aprendizado e na resolução de dúvidas.
- **Documentação Python:** consulta de comandos, funções e recursos da linguagem.
- **Autocompletar:** sugestões de código durante a digitação.
- **Gerenciamento de arquivos:** criação, organização, importação e exportação de arquivos Python.
- **Pastas e projetos:** organização dos códigos em estruturas de pastas.
- **Terminal:** interação com programas durante a execução.
- **Quizzes:** exercícios para praticar e testar conhecimentos de Python.

## 🌐 Acesso online

O PyCode Studio está hospedado no Render e pode ser acessado pelo navegador:

**[https://pycode-studio.onrender.com/](https://pycode-studio.onrender.com/)**

Não é necessário instalar o aplicativo localmente para utilizar a versão online.

## 💾 Arquivos e projetos

Os arquivos do editor são mantidos temporariamente durante a sessão. Atualizar a página preserva o workspace na mesma sessão, enquanto uma reinicialização do servidor inicia um workspace limpo.

Recomenda-se exportar os projetos importantes para guardá-los no computador e importá-los novamente quando necessário.

## 🤖 Tutor IA

A plataforma possui integração com a API Google Gemini para oferecer assistência durante o aprendizado de Python.

A disponibilidade das respostas depende dos limites e da disponibilidade do serviço de IA, podendo ocorrer interrupções temporárias.

## 🔒 Segurança e limitações

O PyCode Studio é uma plataforma de demonstração e aprendizado.

A execução de código Python ainda não utiliza isolamento completo por contêiner para cada usuário. Senha para acessar o Pycode-studio é "0".

## 🎯 Objetivo

Oferecer um ambiente acessível e integrado para apoiar o ensino e o aprendizado de programação Python, reunindo edição, execução, documentação e assistência por inteligência artificial.
